# Windows launcher

`Configure-FatFish.cmd` opens configuration; `Start-FatFish.cmd` can start services
and connect to Discord. Neither is an installation check or part of this local
publication validation. Read [INSTALLATION](INSTALLATION.md) first.

The launcher requires Node/native Opus/FFmpeg, separately prepared Whisper assets,
WSL Ubuntu and an authorized Feiyu environment. Missing local assets stop startup;
they are not implicitly acquired. Adapt helper paths/settings for your machine.
Credentials are stored with current-user DPAPI in local application data and must
never be distributed. This preparation did not inspect operator credential stores.

The launcher forces all-participant passive transcription. Use the manual inert
profile and explicit allowlists where affirmative enrollment is required. Give
notice and obtain participant agreement. Memory/search/text remain separately
controlled, and paid DeepSeek replies require deliberate enablement. Process request
limits reset when restarted and do not establish a durable spending budget.

Voice `/stop` disconnects the session but does not terminate every process or local
model service. The deployment operator controls service shutdown, credentials,
retention, private ACLs and deletion. No saved state, host diagnostics or historical
private startup records are included in this public guide.
