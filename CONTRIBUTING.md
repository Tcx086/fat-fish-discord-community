# Contributing

This is an independent experimental fork. Read [README](README.md),
[privacy](PRIVACY.md), [security](SECURITY.md), [third-party notices](THIRD_PARTY_NOTICES.md)
and the [publication gate](docs/PUBLICATION_GATE.md).

Describe the concrete problem, resulting behavior and focused offline checks.
Follow the existing module structure. Install from the lockfile as described in
[INSTALLATION.md](docs/INSTALLATION.md). Run the relevant tests and disclose any
remaining failures; the full suite has seven inherited failures, not a green result.

Use fictional fixtures. Do not commit credentials, participant conversations/IDs,
private paths, databases, models, voice references, media, dependencies or local
configuration. Retain existing copyright/license notices and supply source URLs,
exact revisions, terms and modification notices for adapted material. Do not
assert authorship or asset rights on another person's behalf.

No CLA or DCO is asserted. Contributions use the applicable component terms;
discuss incompatible material before submitting it. Respect the
[code of conduct](CODE_OF_CONDUCT.md). Private vulnerability reporting is preferred
but remains OWNER_ACTION_REQUIRED; follow SECURITY.md instead of posting sensitive
reports publicly.

Live Discord, paid inference, service starts, model acquisition, publication and
Actions enablement require separate authorization. A contribution or passing test
does not authorize any of those actions.
